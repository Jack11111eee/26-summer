## timer.py 服务形态（difficulty.py 双形态：纯函数区 + 接 conn 区——模块 docstring 照 :27-28 契约）
纯函数区（不持 conn）：
- _ts(iso: str) -> datetime（datetime.fromisoformat——now_iso 产物带微秒+时区全兼容实验 8）
- merge_spans(spans: list[tuple]) -> list[list]（排序合并——实验 5 骨架照 RESEARCH Code Examples #4）
- overlap_seconds(spans_merged, since, now) -> float（min(e,now)-max(s,since) 正则和——单题/全场共用）
接 conn 区（不 commit——调用者主事务统一，docstring 声明 D-06 契约）：
- close_open_interval(conn, session_id, ended_at=None)：UPDATE ended_at WHERE ended_at IS NULL（无 open no-op 幂等）
- open_interval(conn, session_id, interval_type, reason=None)：INSERT + except sqlite3.IntegrityError → close_open_interval 后重试一次（部分唯一索引乐观环——实验 6）
- advance_interval(conn, session_id, interval_type, reason=None)：close ✓→ open（answer 正常路径的单次调用形态）
- paused_overlap_seconds(conn, session_id, since, now) -> float：SELECT paused 行 → merge → overlap
- session_active_seconds(conn, session_id) -> float：active 行 merge + 开放的当前 active 区间截到 now
- seal_if_question_timed_out(conn, session_id, question_id, user_id) -> bool：当前题 activated_at（NULL 返 False——Pitfall 10）；now - activated_at - paused_overlap > QUESTION_TIMEOUT_MINUTES*60 → 封存（UPDATE answered_at=None? 否——timeout 封存 answered_at 不写值仅 closed_at+seal_reason='timeout'——照 02-04 refused 路径形成：UPDATE closed_at, seal_reason='timeout'，answered_at NULL 保持；QUESTION_SEALED 事件 payload seal_reason='timeout' + QUESTION_TIMEOUT 事件（§13.2 枚举 QUESTION_TIMEOUT 独立于 SEALED——两事件同事务）+ EVIDENCE_EVALUATED 不写（未作答无证据）→ return True（调用方据此走下一题派发而非决策链）
