## 11. 三大标准落点

| 标准 | 落点 | 实现 |
|---|---|---|
| ①全链路可审计 | report→session→(model,version)→question→message→trace 锚定链 | llm_trace 扩 5 类型 + P8 trace 查看器 |
| ②反馈可回溯 | 异议/bad case 双端 | candidate 报告页每分数旁「异议」→feedback 表；admin「标 bad case」；不做改分；双分背离≥2 级自动候选 |
| ③有测评标准 | b+c 评测 | **排期：联调全绿后最后做**；eval/ 目录独立可迁移 |

## 12. 评测与 UI

- **一致性（b）**：固定 transcript 复跑断言 score_final 分差≤1（temperature=0；score_live 属过程值不在此断言范围）；
- **虚拟考生（c）**：三档脚本（强/中/弱）端到端，断言档位正确区分（强>中>弱）+ 短板定位符合预设；
- **黄金集（a，模块一）**：推后至真实数据收集后；
- **P8 测试中心**：三 tab = 评测运行 / trace 查看器 / 反馈·bad case。
