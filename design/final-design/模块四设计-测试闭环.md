## 1. 三大标准落点

| 标准 | 落点 | 实现 |
|---|---|---|
| ①全链可审计 | report → session → model/version → question → message → score → trace，经 `trace_link` 统一关联表闭合 | trace 查看器（admin）+ trace_link |
| ②反馈可回溯 | 候选人逐分异议 → feedback（不改分）；admin 审核标记 bad case；双分背离自动候选 | feedback 表 + bad case 流 |
| ③有测评标准 | b+c 评测；eval/ 目录独立可迁移 | 评测运行器 + eval_results |

## 2. 评测契约

### 2.1 一致性测试（b）

- 固定 transcript 复跑，断言 **score_final 分差 ≤ 1**；
- 固定条件：model/provider/版本、temperature=0、rubric 与模型快照、（若适用）随机种子；
- score_live 属过程值，不在断言范围。

### 2.2 虚拟考生测试（c）

- 强/中/弱三档脚本端到端；
- 断言：总分排序（强 > 中 > 弱）**+ 短板定位符合预设 + required 覆盖 + 拒答/缺失状态 + 证据引用 + 报告状态**（当前仅验证排序，短板断言未接入，需补）。

### 2.3 自动 bad case 候选

```
score_live 与 score_final 可比 且 |live − final| ≥ 配置阈值
→ 创建 bad_case_candidate（排除：题目无效 / 模型不确定 / 系统错误 / 状态不可比）
→ 管理员审核确认，不自动改分
```

### 2.4 数据隔离

- **eval 必须使用独立/临时数据库**，不写业务库（当前虚拟考生直接写业务库为必改项）；
- eval 运行留 eval_results；runs 参数需边界校验。

### 2.5 黄金集（a）

本期推迟（真实数据收集后另行排期），不作为本期验收项。

## 3. 测试与验收要求

- **统一 pytest 收集**：现有脚本式测试（test_m6_backend.py 下划线函数仅在 `__main__` 执行、test_question_bank.py 带参 test_* 被 pytest 误收集）需重构为可收集 pytest 或明确独立命令；CI 为正式验收入口；
- **M1 回归为动态测评实施硬前置**（清单见《模块一设计》§8）；
- **候选人端完整 E2E 为 M5–M7 verified 必要条件**：注册→登录→选岗→session→首题→作答/追问→表单→完成→评分→报告→异议，另测刷新恢复 / 断线重试 / 超时 / 越权 / 报告失败重试；
- 越权权限矩阵（candidate↔candidate 读写 session/report/form/feedback、admin 边界）为上线阻断测试；
- 必测补充：幂等与并发、计时、迁移、SSE、畸形 JWT、上传限额、路由冲突（/jds/orphan）；
- mock 回归只做工程回归，**不能替代真实 LLM 质量验证**；
- prototype 为视觉参考，静态原型不作功能/API 验收依据。

## 4. trace 与审计

- trace_link 关联角色：input / output / caused_by / scored / reported / source；唯一约束 (trace_id, entity_type, entity_id, link_role)；
- 旧 trace 的自由文本 ref_id 在迁移时导入 trace_link，补 refine(raw_hash) / question_gen(item_id) / aggregate(model_id) 的关联；
- 管理员查看 trace 全文（含 prompt/response、候选人原文）须留 `REVIEW_ACCESSED` 访问审计；
- trace 完整保存 prompt/response（数据分级、保留期、脱敏实施期细化）。

## 5. 里程碑状态口径（四维）

每个里程碑记录 `implemented / contract_complete / verified / production_ready`。当前 M5–M7 主体 implemented、contract_complete=false、verified=false；verified 以 §3 的测试与 E2E 通过为判定条件。

## 6. 重构注意（模块四部分）

- 自动 bad case 候选逻辑当前完全未实现（设计有、代码无）；
- eval 隔离（独立 DB / 事务回滚 / 清理策略）；
- feedback 补 user_id / note / reviewer / updated_at；admin review 的 note 当前被丢弃；
- eval 触发参数校验与任务失败可见性（异常字符串不得直接入库为结果）；
- 后台评测任务同报告任务：失败显式状态，不静默。
